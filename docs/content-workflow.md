# 内容维护流程

本流程用于受信任的仓库内容及本地生成规则，不是后台审批系统。当前数据来源情况见 [内容基准](content-baseline.md)。

数学计算题尽量不使用固定题库，优先按经审核的运算规则和数值边界动态生成，减少反复遇到相同题目。固定题目仅按实际需要保留为示例、回归样例或用于必须固定内容的场景；动态生成不放宽年级、知识点及内容审核约束。

数字消除的动态规则见 [生成规则审核](content-review-generation.md)：先记录规则的数值边界、知识点映射、实际呈现、审核主体与时间，再穷举检查合法候选、校验关联并通过 selectExercises 正式筛选。不以已有单题的 approved 状态自动授权其任意变形。规则实质变化需重审并更新版本；候选预览仍独立，不作为正式题量不足时的降级。

## 内容位置与编号

| 对象 | 文件 | 维护约定 |
| --- | --- | --- |
| 教材槽位 | src/content/textbooks.ts | CH/MA/EN + 年级 + A/B；独立于正式出版物身份 |
| 单元和插入板块 | src/content/units.ts | U 为主单元，PRE/P/A/R 为其他板块；order 单独排序 |
| 知识点和映射 | src/content/skills.ts | 能力 ID 与教材分离，Mapping 引用具体单元 |
| 练习 | src/content/exercises.ts | 当前仅数学；稳定 ID、mappingIds、gameIds、结构化 task |
| 动态规则 | src/game/number-puzzle/generation.ts、choice-generation.ts | 整数与结构化选择题；固定数域、候选、版本及真实审核范围，经正式筛选后组卷 |
| 来源 | src/content/evidence.ts | 当前仅支持会话交接；新增来源种类时同步模型与校验 |

修改展示名称或排序不更换稳定 ID。发现错误内容时先移出正式范围并记录原因；引用仍存在的 ID 不应直接删除或复用。

## 新增或修订内容

1. 先确定目标游戏、训练能力和年级范围，检查现有知识点及教材关联能否表达。
2. 保存实际取得的来源信息和检查范围；无法取得版权页、目录或正文时，明确哪些结论仍待核验。
3. 录入目录与映射并保留对应状态。目录标题不能单独证明某项教学能力已完整覆盖。
4. 编写 draft 练习，检查任务、答案、数值边界、干扰项和游戏呈现。
5. 执行引用校验与相关测试；人工或代理审查题意和适配性，记录范围与结论。
6. 满足练习审核要求后才设置 approved，填写真实审核主体和 ISO 时间；审核记录随提交保留。
7. 用正式筛选与候选预览分别检查年级、学科、gameId，不将草稿作为缺题降级路径。

## 审核状态的含义

| 状态 | 证明什么 | 不能据此推断 |
| --- | --- | --- |
| sourceVerification | 已完成所记录范围的来源核对 | 已确认深圳选用或所有教学目标 |
| localAdoptionVerification | 已确认目标地区、学年实际选用 | 所有知识点映射都正确 |
| curriculumVerification | 具体映射已对照内容与教学要求核验 | 练习已完成呈现和难度审核 |
| review.status = approved | 该练习已按记录范围完成审核 | 教材来源、地区选用及教育效果均已验证 |

不得用改字段代替审核，不编造身份或“专家审核”。代理可以记录实际完成的检查，但不能把计算验证包装成教师评审；缺乏依据的教学结论保持待处理。

## 练习审核记录

每次晋级、撤回或实质修改，在内容变更说明或提交关联的审核文档中记录以下信息；首批静态题见首批审核记录，动态题见生成规则审核。

- 对象：练习 ID、变更版本或提交、游戏与年级。
- 表述：玩家实际看到或听到的题意，是否可理解、有无歧义。
- 正确性：答案、干扰项、等价答案与必要边界。
- 适配性：知识点、数值范围、所需前置能力，以及游戏操作是否泄露答案。
- 依据：实际读取的材料与页码或位置；通用原创练习明确标记，不虚构教材出处。
- 结果：通过、修改后重审、暂缓；实际审核者、时间与未覆盖事项。

这是记录要求，不新增当前代码不支持的字段。reviewer 与 reviewedAt 仍是模型中的最小审核元数据；更细记录通过可追溯文档关联，不假定代码自动验证其充分性。

## 来源与资源

教材封面、版权页、目录页分别支持系列、版本身份与目录核对。国家审定目录不单独证明深圳所有学校选用。第三方资料保留第三方身份；会话交接不升级为原件来源。

内容证据与游戏素材分别登记。后续图片、音频和文字在实际引入时记录来源、可用范围与替换方式；不要把整本教材或无法确认可用性的素材直接打包进游戏。仅为核验不要求收集完整教材正文。

## 验证限制

当前检查覆盖结构关联、部分元数据及安全整数计算，不检查全部题目范围、语文语义、英语发音或阅读教学目标。内容变化需要补充对应测试和审核，方法见 [验证说明](../VERIFICATION.md)。
