# 视觉与交互规范

适用对象是复古掌机学习游戏。数字消除的正式入口已采用下述数字花园视觉；其他游戏仍为独立风格原型。

2026-10-26 已确认的 [挑战、学习与金币规则](gameplay-learning-economy.md) 已实现：挑战每题 10 秒，学习和错题复习不限时。计时只在题目可读、可操作时运行，不占用动画或弹窗时间；暂停冻结计时。商店、道具、课程与玩家资料应沿用当前数字花园视觉，新增界面采用 DOM 按钮、表单和原生模态 dialog，挑战与练习复用 Canvas 棋盘。已完成桌面浏览器模拟和截图检查，见 [验证记录](evidence/learning-economy/README.md)；真实设备仍未验证。

## 方向

采用掌机屏幕、游戏区域与明确操作区的视觉结构，让孩子理解当前任务和可操作目标。像素风可用于边框、图标、角色与场景；中文、拼音、英语和算式优先使用清晰字体，不强制像素化文字。

保持有限且一致的配色、清晰层级和足够对比。颜色表达选中、可操作或答题结果，但同时提供文字、形状或图标反馈。避免装饰性渐变、发光、玻璃效果和遮挡题目的过度动画。

首阶段不引入复杂角色资源、地图编辑器或装饰素材包；必要视觉资产随游戏逐步增加。

## 数字消除：数字花园

- 页面使用浅纸色背景、薄荷绿机身、木牌标题与奶油色内容卡，主操作使用深绿按钮。年级选择、可用内容、恢复、记录、结算与异常提示使用同一套配色。
- 局内保留 360×620 逻辑画布与 3×4 棋盘；蓝色数字块采用厚描边、硬投影与明暗边。题目、点阵、题数、得分和正确／错误反馈保持清晰，花园与蓝蓝为静态装饰，不代表额外规则。
- 暂停使用深绿休息站遮罩；低高度视口允许页面纵向滚动。画布可用空间扣除外框内边距与边框，最小缩放保持数字块可点选。
- `web/game-style/` 仍是九款独立展示原型，正式入口不引用其展示题、导航或交互脚本。

## 布局与输入

- 手机优先，游戏区域、题目、反馈和操作区有稳定位置，避免作答后布局跳动。
- 常规导航、年级选择和设置使用标准可操作控件；游戏区域按实际需求绘制。
- 手指操作不依赖 hover；控件留足触摸与间隔空间，错误点击不能造成不可逆惩罚。
- 页面滚动与游戏手势不冲突；未来拖拽玩法提供点选后放置的替代操作。
- 不用动画或限时压力掩盖题目；核心结果在动画结束前后保持一致。
- 导航、暂停与返回可识别，连续点击不会重复触发局次或计分。

## 内容状态

年级可选择不等于全部有题。展示实际可用范围，无内容时给出清楚提示和返回入口。候选内容预览使用显式标记，不与面向玩家的默认游戏混用。

听辨任务中，答案文字不能直接泄露结果；音频不可用时说明状态。音效关闭后仍能理解普通操作与答题反馈，但不能据此假定听力任务仍可进行。

## UI 验收

- 检查真实渲染的汉字、拼音变音符、算式和长文本，无截断或错误替换。
- 检查窄屏、常见手机、桌面尺寸和横竖屏切换后的可操作性；记录测试尺寸与设备。
- 检查选中、禁用、答错、暂停、空内容与离线缺失状态。
- 检查触摸、重复点击、后台切换与关闭音效。
- 使用截图或录屏证明结果，区分浏览器模拟与真实设备。

游戏风格与完整流程的最终验收以 [PLAN.md](../PLAN.md) M4、M7 为准。
