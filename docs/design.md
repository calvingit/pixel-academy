# 视觉与交互规范

适用对象是数字花园主题学习游戏。2026-10-26 按用户要求重新设计正式数字消除的交互与 UI；其他游戏仍为独立风格原型。

2026-10-26 已确认的 [挑战、学习与金币规则](gameplay-learning-economy.md) 已实现：挑战每题 10 秒，学习和错题复习不限时。计时只在题目可读、可操作时运行，不占用动画或弹窗时间；暂停冻结计时。商店、道具、课程与玩家资料应沿用当前数字花园视觉，新增界面采用 DOM 按钮、表单和原生模态 dialog，挑战与练习复用 Canvas 棋盘。已完成桌面浏览器模拟和截图检查，见 [验证记录](evidence/learning-economy/README.md)；真实设备仍未验证。

## 方向

采用清晰的任务卡、数字棋盘与独立操作区，让孩子理解当前任务和可操作目标。像素元素保留在品牌和角色细节；中文、拼音、英语和算式优先使用清晰字体，不强制像素化文字。

保持有限且一致的配色、清晰层级和足够对比。颜色表达选中、可操作或答题结果，但同时提供文字、形状或图标反馈。避免装饰性渐变、发光、玻璃效果和遮挡题目的过度动画。

首阶段不引入复杂角色资源、地图编辑器或装饰素材包；必要视觉资产随游戏逐步增加。

## 数字消除：数字花园

- 页面使用暖纸色背景、森林绿主操作、奶油色卡片与少量收获黄。取消厚重的掌机外壳与满屏高饱和装饰，用插画和留白表达花园主题。
- 主界面按手机单屏设计，只展示当前任务。首页保留年级选择、开始／续局与紧凑资料栏；课程、错题、商店、收藏和练习记录收进“更多”弹窗。介绍文案移除，装饰仅在空间足够时出现。
- 年级保留任意多选，以勾选、边框和底色共同表达选择；查看可用范围后才开始挑战。其他年级暂无内容的状态不自动降级。
- 局内用真实剩余空间重排题卡与十二个数字块：竖屏三列四行，低高度横屏四列三行、题目在左；绘制、指针命中和键盘导航共用布局几何。点阵随题卡调整行距，不压扁数字或整张画布。
- 局内仅保留音效、倒计时、题目／得分／进度、数字块与道具／操作；隐藏钱包和复活统计。最后三秒以文字秒数和警示底色表达。解题讲解点开弹窗，不常驻挤占棋盘。
- 暂停和准备状态使用浅绿休息卡；课程、商店、资料、原生 dialog 与结算统一卡片样式。保留秋日、雪地配色和装饰，以及已购头像、皮肤的预览与装备路径。
- `web/game-style/` 仍是九款独立展示原型，正式入口不引用其展示题、导航或交互脚本。

## 扩展题型

选择题沿用纸色题卡与森林绿主操作，采用原生 DOM 按钮和可见题目标题；新题目出现时焦点移到标题。多选按钮使用勾选、边框和 `aria-pressed` 同步表达状态，提交按钮固定可见，空选择禁用。候选排列在同一道题内固定，选择时不披露对错或答案个数。

竖屏候选两列；低高度横屏三列，与原数字棋盘分别布局。算式选项独立缩小字号以保持整式可读，分组图示使用与题意一致的圆点组。暂停时完整隐藏选择题卡，提示区和复活弹窗沿用现有规则；减少动态效果设置禁用淡出过渡和缩放。

## 布局与输入

- 手机优先，主流程操作按钮保持单屏可见；页面用 100dvh 和安全区边距，棋盘由 ResizeObserver 根据可用容器重排。课程／商店等长列表只在内容区滚动，返回操作固定可见，不靠整页滚动找按钮。
- 常规导航、年级选择和设置使用标准可操作控件；游戏区域按实际需求绘制。
- 手指操作不依赖 hover；控件留足触摸与间隔空间，错误点击不能造成不可逆惩罚。
- 页面滚动与游戏手势不冲突；未来拖拽玩法提供点选后放置的替代操作。
- 不用动画或限时压力掩盖题目；核心结果在动画结束前后保持一致。
- 导航、暂停与返回可识别，连续点击不会重复触发局次或计分。

## 内容状态

年级可选择不等于全部有题。展示实际可用范围，无内容时给出清楚提示和返回入口。候选内容预览使用显式标记，不与面向玩家的默认游戏混用。

听辨任务中，答案文字不能直接泄露结果；音频不可用时说明状态。音效关闭后仍能理解普通操作与答题反馈，但不能据此假定听力任务仍可进行。

## UI 验收

- 检查真实渲染的汉字、拼音变音符、算式和长文本，无截断或错误替换。
- 检查窄屏、常见手机、桌面尺寸和横竖屏切换后的可操作性；记录测试尺寸与设备。
- 检查选中、禁用、答错、暂停、空内容与离线缺失状态。
- 检查触摸、重复点击、后台切换与关闭音效。
- 使用截图或录屏证明结果，区分浏览器模拟与真实设备。

游戏风格与完整流程的最终验收以 [PLAN.md](../PLAN.md) M4、M7 为准。
