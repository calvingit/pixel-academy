# 数字消除：挑战、学习与金币规则

确认日期：2026-10-26。状态：已实现并完成桌面浏览器验证；真实设备、教学效果与生产部署未验证。验收证据见 [验证记录](evidence/learning-economy/README.md)。

用户已确认按本轮完整梳理的建议执行。本文是新版挑战、课程、错题、金币和商店的需求依据；与 [现有玩法说明](gameplay-number-puzzle.md) 冲突时，新版预期行为以本文为准。现有代码已替换无倒计时、无限重试和自动提示规则；旧中断局不再恢复，历史设置与成绩只读导入，不补发金币、不删除旧数据。

未修改的题目呈现、3×4 棋盘、补块、正确答案可达保证、年级选择、正式内容筛选和动态组卷规则继续沿用现有玩法。当前只扩展数字消除，不启动 M8–M15 的其他游戏。

## 1. 体验与术语

核心循环：免费学习与错题复习 → 获得金币 → 挑战游戏 → 购买道具与装扮 → 回顾错题。

| 术语 | 定义 |
| --- | --- |
| 挑战 | 正式数字消除局次，每局 10 题，每题倒计时 10 秒 |
| 中断 | 当前题答错或超时，停止计时与作答，等待复活或结束挑战 |
| 复活 | 消耗一张复活卡重答当前题，一局最多成功复活 2 次 |
| 首次答对 | 本题第一次尝试在截止前答对，且未使用提醒卡；使用加时卡不取消此资格 |
| 辅助完成 | 使用提醒卡或经历复活后答对，不计入首次答对 |
| 课程完成 | 完成知识说明、示例和该课程定义的课后小练习通过条件 |
| 待复习错题 | 曾经实际选择错误、尚未标记已学会的题目 |
| 待练习题 | 曾经超时、尚未完成练习的题目；超时本身不认定为选择错误 |
| 已学会 | 错题复习答对后由玩家确认，移出待复习列表；不是永久排除游戏出题 |
| 金币 | 本机档案内的虚拟奖励，不是真实货币，不可充值或兑换现金 |

挑战允许任意单选、多选年级；只使用实际可用的所选年级内容，不以其他年级补题。学习与错题复习不限时，不消耗复活卡。首版不额外增加独立普通练习模式，由课程练习与错题复习承接。

## 2. 挑战与计时

1. 选择年级，展示实际内容范围；无正式内容或组卷条件不满足时不允许开始。
2. 开局前显示道具库存及商店入口，生成正式 10 题局；刷新续局不重新抽题。
3. 题目、棋盘完整显示且可操作后开始 10 秒倒计时。消除、补块、错误反馈和复活弹窗不占答题时间。
4. 在截止前作答正确，立即锁定结果、停止本题计时，计分后进入下一题。正确块可达保证不变。
5. 选择错误立即记录一次答错并进入中断；截止时尚未有效作答，记录一次超时并进入中断。到达截止时刻后的点击按超时处理，不能同时判为答对或重复中断。
6. 暂停或切后台冻结剩余时间；恢复前台不自动继续。暂停、动画和弹窗期间禁止作答及使用加时卡。接受暂停带来的额外思考时间，不按竞技考试设计防暂停机制。
7. 刷新、关闭后续局保留剩余时间、当前题、已记录结果、复活次数和道具使用状态；不能重置时间或撤销消耗。
8. 10 题全部完成后通关；拒绝复活或复活次数耗尽后失败。结算展示分数、首次答对数、辅助完成数、答错数、超时数、复活次数和金币明细。

题目计时、输入截止判定与暂停冻结使用一致的时间依据；逻辑不以动画帧数或动画回调先后作为判题依据。连续点击、迟到回调与计时事件竞争只能产生一次有效结果。

主动退出、确认重新开始均放弃本局未结算金币，操作前明确提示；暂停和正常续局不算主动退出。已经购买或使用的道具不因弃局返还，已有钱包余额不被没收。

## 3. 中断与复活卡

- 答错和超时共用每局最多 2 次复活额度；本局第 3 次中断直接失败。两次复活都用于同一道题也允许。
- 还有额度时弹窗显示中断原因、剩余复活次数、库存和“结束挑战”。有卡显示“使用复活卡”；无卡显示价格、余额、购买后余额及“购买并使用”。
- 不默认选中购买、不自动扣币或用卡。余额不足时说明差额，可结束挑战；不跳转课程赚币后回到此局补买。
- 成功复活消耗一张卡和一次额度，保留已发生的答错、超时和错题记录；棋盘不重抽，重答当前题。
- 复活后进入不计时的“准备继续”状态。可以先使用已开放的提醒卡，点击“继续答题”后重新获得 10 秒。
- 次数用完后不再展示可购买复活的操作；即使有多张库存也不能继续。
- 购买并使用必须整体成功：扣币、消耗购买的卡、增加复活次数并恢复题目一致落盘；失败不能只扣币。重复点击、刷新与恢复不得重复扣费或复活。

## 4. 提醒卡与加时卡

### 提醒卡

- 整局累计实际答错 2 次后开放，超时不计入阈值；取消旧的同题答错 3 次自动高亮。
- 满足条件后，当前题复活的准备阶段、后续题开始前或正常作答期间均可手动使用；每题最多一张。下一题开始前提供同样的准备入口，不靠抢在倒计时中操作。
- 只使用已有库存，局内不购买；库存不足时说明原因，不自动提示答案。
- 使用后高亮本题所有正确数字块，直到该题结束；仍需玩家主动点选，不自动作答。
- 不增加时间、不清除错误、不恢复复活额度。效果及已使用标记跨同题复活和续局保留，不能再次扣卡。
- 本题标为辅助完成，即使第一次点选答对也不享受首次答对奖励。
- 如果两次中断包含超时，本局可能未达到提醒卡开放条件；界面展示实际答错数和开放条件，不将超时偷偷计入。

### 加时卡

- 正常作答且尚未到截止时刻时，手动使用一张，给当前剩余时间增加 5 秒。
- 每题最多使用一张，次数覆盖该题全部尝试；复活后不能再用第二张。
- 复活重新获得 10 秒，先前增加的时间不结转；提醒卡效果则按上文保留。
- 不清除错误、不占复活次数、不泄露答案，不取消首次答对和全首次答对奖励资格。
- 超时、暂停、中断、准备继续和动画期间不能使用；到期后的点击不能通过加时撤销超时结果。
- 局内只使用库存，不打开购买流程。按钮显示库存与“+5 秒”，连续点击只消耗一张。

## 5. 分数与金币

分数记录本局表现，金币用于商店；不能购买分数、通关结果或修改历史成绩。

| 行为 | 分数 | 金币 |
| --- | ---: | ---: |
| 本题首次答对，未用提醒卡 | 10 | 2 |
| 答错或超时后复活答对 | 5 | 0 |
| 使用提醒卡后答对 | 5 | 0 |
| 通关 | 不额外加分 | 额外 5 |
| 10 题全部首次答对，未用提醒卡或复活 | 按题计分 | 再奖励 5 |
| 首次完成一节课程 | 不计挑战分数 | 10 |
| 同一道错题首次在复习中独立答对 | 不计挑战分数 | 2 |

- 通关或失败时统一发放本局金币；失败保留已获得的答题金币，不发通关及全首次答对奖励。满首次答对局为 100 分、30 金币。
- 主动退出、重新开始不发本局金币；没有答对任何题的失败局为 0 金币，不倒扣已有余额。
- 本局未结算收益不能用于局内购买复活卡；只能花已有钱包余额。
- 结算分别显示答题、通关、全首次答对奖励，学习及复习分别显示奖励来源；辅助完成明确说明本题不发答题金币。
- 同一局只结算一次。同一课程和同一道错题的奖励资格单独保存，不随成绩列表裁剪、改标题、排序或普通清除成绩而重置。
- 候选预览不产出正式金币，不消耗正式库存、不改变正式课程与错题领奖状态。
- 每份本机档案首次赠送 20 金币、2 张提醒卡；领取标记与钱包一起保存，刷新、更新、清除成绩不重复发放。
- 删除旧建议“重试答对 1 金币”；重试必须复活，统一按复活题 0 金币处理。

## 7. 学习课程

- 首版围绕现有已审核的数学知识点提供短课程，不同时扩展其他学科、游戏或未准备好的年级。
- 每课包含知识说明、示例和课后小练习；课程与练习的年级、知识点、审核和来源约束沿用 [内容维护流程](content-workflow.md)。正式练习仍只经 selectExercises 获取，不将草稿自动降级为正式内容。
- 学习始终免费、不限时，不使用复活卡或提醒卡限制讲解；可反复阅读、看讲解和重做。
- 必须完成说明、示例及课后小练习才算完成，不能仅点击“看完了”领取金币。
- 五节首版课程均为三道不同的小练习；首版统一要求该轮三题全部独立答对。看过某题答案后可继续学习，但需重新完成一轮小练习才达到领奖所需的通过条件。
- 首版课程为认识数字、加法入门、减法入门、连续加减、乘法点阵。知识点、示例和审核范围见 [课程审核](content-review-courses.md)；未审核课程不开放。
- 显示“未学习／学习中／已完成”，中断保留进度；首次完成奖励 10 金币，重复学习不重复发奖。
- 课程稳定标识不随标题、排序或小幅内容修订改变；不能靠更新课程重新发同一课程奖励。
- 课后小练习实际选错的题目进入同一错题集；失败重做不消耗金币或道具。

## 8. 错题、待练习与已学会

### 收集与身份

- 收集挑战、课程小练习和错题复习中曾经实际选错的题目，保存当时原题、必要呈现信息及错误次数。复活答对不删除已记录的错误。
- 同一道题多次选错合并为一条，累计错误次数，不因换局、生成 ID 或进入来源不同而重复建条目。
- 超时单列待练习，不增加答错次数，也不触发提醒卡阈值；同题既答错又超时时以错题为主，保留超时记录，避免两处重复待办。
- 动态题按题型、运算数值、步骤及其顺序、答案和影响题意的呈现方式识别同题，不仅依赖生成 ID。相同题型和参数的题即使生成版本或 ID 改变，也不能重复领奖；不同题意不能只因答案相同而合并。
- 错题是必须保留原题的固定内容场景，不用重新随机生成的相似题替换。正式复习仍通过 selectExercises 对符合现行审核范围的原题筛选；规则撤回或原题不再可审核使用时，保留历史记录并说明暂不可练习，不自动使用其他题冒充。

### 复习与奖励

1. 从待复习错题集中取原题，不限时，先让玩家重新作答。
2. 提交后提供答案与讲解；玩家也可主动查看，不收金币或卡片。
3. 同题首次在复习中未先看答案、独立答对，发放 2 金币。挑战答对不替代此奖励条件。
4. 查看答案后的同次作答不发奖；以后重新进入、未先看答案且独立答对，尚未领过该题奖励时可以领取。不能通过重新打开反复发奖。
5. 复习答对后开放“已学会”，同时允许选择继续练习。已学会只移出待复习列表，按钮本身不发金币；学习结果不因使用过免费讲解而禁止保存。
6. 已学会记录仍可查看原题、讲解或撤销掌握状态。撤销不重置领奖资格。
7. 正常挑战仍可能出现已学会题；再次选错时重新进入待复习，保留历史错误与奖励记录，不再发放已经领过的同题奖励。

仅超时的待练习题可以免费练习，答对后移出待练习；不享受错题首次复习的 2 金币奖励，除非该题也实际选错并符合错题奖励条件。

## 9. 收藏与结果反馈

- 收藏图鉴展示已拥有的头像、皮肤，以及选定下一件目标的价格和差额。
- 通关评价按首次答对数量反馈表现，采用一至三星；首次答对 10 题三星、8～9 题二星、其余通关一星，不能影响本文的金币计算，也不能把辅助完成算成首次答对。
- 失败局展示完成进度、答错与超时原因，提供免费错题回顾，不使用羞辱或负面能力标签。分数和星级不等于课程掌握程度。
- 成就徽章后续再补；首版不增加复活次数升级、金币倍率、连续签到、随机宝箱、体力等待、充值、广告换币或付费知识解锁。

## 10. 保存、更新与异常

- 保存钱包、库存、购买与装备、昵称、新手礼包标记、课程进度与领奖资格、错题与掌握及领奖状态。
- 保存当前局的完整题目、剩余时间、答错和超时记录、累计复活次数、每题道具使用与效果、待结算奖励和是否已结算。继续沿用恢复不重新抽题的要求。
- 金币增减、卡片消耗、购买解锁和对应的领取／使用标记必须一致保存；重复点击、刷新恢复、迟到回调及多页面操作不能重复领取、扣费或覆盖出负余额。冲突时拒绝陈旧操作并要求同步状态，不静默覆盖。
- 保存失败明确提示未成功，不能显示“购买成功”或“奖励已到账”；不能形成扣币但未到账、发奖但未记录领取资格的半完成结果。
- 存储不可用时允许临时学习与挑战并说明无法持久保存；禁用购买、消耗库存和持久领奖，不能假装永久拥有。恢复存储后不能自动补发未持久确认的交易。
- 更新不重置钱包、购买与领奖资格。已有数据的迁移和旧中断局兼容需在实现前核对实际格式与消费者，不在本次文档中删除存储键或迁移路径。
- “清除成绩”只清除成绩，不重置钱包、购买、课程领奖或错题领奖资格；“重置全部数据”单独确认，明确清除全部本机档案与当前局。普通清除不能被用于重复领取奖励。
- 本机档案无跨设备同步；清除浏览器站点数据、重置全部档案或更换设备会失去金币、装扮、进度与领取标记。重建本机档案可重新获得新手礼包，本地方案不承诺防篡改或跨档案去重。
- 缓存就绪后，课程、商店素材、讲解、挑战和记录均应可离线使用；首次缓存未完成不承诺离线可用。更新不得混用进行中局次的内容和规则版本。

## 11. 典型路径与验收边界

以下为验收场景，已执行检查与未覆盖事项按 [验证记录](evidence/learning-economy/README.md) 区分；不将清单本身当作测试通过证明。

| 场景 | 预期 |
| --- | --- |
| 全部首次答对 | 100 分、30 金币；重复打开结算不再发奖 |
| 使用加时卡后仍全部首次答对 | 消耗库存一张，当前题加 5 秒；保留 100 分和 30 金币资格 |
| 同题连续答错两次并分别复活 | 累计用卡与复活次数各 2；提醒卡开放，准备继续时可使用；本题答对为 5 分、0 金币 |
| 第三次答错或超时 | 直接失败，不能继续购买复活次数；发放此前已获得的答题金币 |
| 两次超时后复活 | 答错数仍为 0，提醒卡未开放；再中断失败 |
| 到期瞬间点击答案或加时 | 按统一截止时间只产生一个结果，不撤销已发生的超时 |
| 同题加时后复活 | 重新从 10 秒开始，不能再用加时卡；已有提醒卡效果保留 |
| 暂停、后台、刷新和恢复 | 剩余时间、复活额度、库存、效果和领取状态保持；不会重新抽题或重复扣费 |
| 买卡失败或重复点击购买 | 不出现半完成交易、负余额或重复扣费；错误原因可见 |
| 主动退出或重开 | 提示放弃本局收益；已有钱包不扣除，已消耗道具不退回 |
| 首次完成课程后重复学习 | 仅首次完成加 10 金币；改标题、排序、清除成绩后不重复发奖 |
| 同题多次选错、换生成 ID | 合并错误记录，奖励资格不重置；原题可准确回放 |
| 复习看答案后答对 | 可以标记已学会，同次不发金币；已学会按钮不发奖 |
| 已学会后再次答错 | 回到待复习列表，保留旧奖励标记，不能再领同题奖励 |
| 超时题练习答对 | 移出待练习，不按错题自动发奖 |
| 候选预览与正式档案 | 不产出正式金币、不消耗或修改正式库存和学习进度 |
| 购买、装备与改名 | 余额、解锁和使用标记一致；已拥有商品不能重复买，无效改名不扣卡 |
| 离线与更新 | 缓存完成后断网重开可学习、挑战、购买并记录；进行中内容与规则版本不混用 |
