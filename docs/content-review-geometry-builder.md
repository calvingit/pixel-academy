## 审核方法与范围

1. **形状集审核**：四种立体图形为一年级上学期通用数学事实（对应 MA-01A-U05「认识图形」课次的候选范围口径），不宣称对应教材页码；形状身份词表 `SHAPES_3D` 与中文名映射 `SHAPE_LABELS` 由 `src/learning/shapes.ts` 导出，内容与判题两侧共用防漂移。
2. **逐条任务审核**（下表）：题面表述、积木集、分区/槽位 accept 集合、干扰项可解释性、多解与错误例、图片—形状对应、判题一致性。
3. **结构校验**：`validateShapeTask` 强制身份词表内、候选互异、答案可达、分类区 accept 恰一个形状且互异、每区/槽至少被一块积木满足（无死区/死槽）；`tests/shapes.test.mjs` 覆盖判题矩阵、等价解集合逐成员、63 种年级组合。
4. **渲染图防混淆自检**（见「审核局限」第 2 条）：等轴测 SVG 需呈现立体特征——球体带高光与投影、正方体/长方体可见三个面、圆柱可见顶面椭圆；窄屏（320px）下球 vs 圆、正方体 vs 正方形可区分。渲染图核对以最终渲染截图为准（验证轮留证）。

## 审核局限（如实记录，不以下一轮「应该可以」填补）

1. 题面与图形的**教学适宜性未经真人复核**（无具备教学资质者参与）；一年级学生对「长方体/正方体」命名的可读性、对等轴测示意图的立体感感知未经真实学生验证。
2. 配图辨识度仅经代理目视（自检口径见上），**未经真实学生/教师确认**；渲染截图核对在验证轮补证。
3. MAP-030 与 MA-01A-U05 的来源核对、地区选用与映射核验均为 **pending**；approved 不宣称与特定教材版次对齐。MA-01A-U05 课次（认识图形、我说你做、怎样搭得高）为候选记录（lessonCoverage: examples），不视为全部课次。
4. 首版无旋转操作（实施计划决策 6），积木以标准方向呈现；「允许/禁止旋转」验收按禁止口径覆盖。
