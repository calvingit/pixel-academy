### 桌面验收轮发现并修复的缺陷

1. **✗/✓ 反馈从未可见（实现缺陷，已修复）**：`renderQuestion` 每次渲染把反馈条重新隐藏，送达反馈在 900ms 窗口内实际不可见。修复为反馈仅在 `advance`（推进/终局）与 `selectParcel`（新动作）时隐藏；修复后 E4/E5/E6 反馈可见性断言通过。该缺陷由桌面验收轮的「等待反馈可见」断言暴露（此前仅存在本轮构建中，未发布过）。
2. 验证工具侧两处（非游戏缺陷）：无头 Chrome 默认窗口高度下站位行位于折叠线以下，真实鼠标点击落在视口外——驱动脚本点击前增加 `scrollIntoView` 并以 1280×900 窗口启动；复用含旧 SW 缓存的 Chrome 档案导致页面由旧构建提供——清档案重启后消除。
