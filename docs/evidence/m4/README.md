### ⑤ 暂停 / 继续 —— 通过

| 窗口 | 操作 | 实际 |
| --- | --- | --- |
| asking（题目进行中） | 点「暂停」 | 覆盖层出现（「⏸ 已暂停」+「继续游戏」按钮，虚线边框+形状标记），按钮文案变「继续」；棋盘点击被忽略（覆盖层拦截 + 会话守卫双保险）；点「继续」恢复 |

## 验证过程中发现并修复的缺陷

1. **结算后再开一局报错（阻塞缺陷）**：完整打完一局后「再来一局 / 返回后再开」抛 `beginRound requires idle status, got finished`——`main.ts` 的 `teardownRound` 只在 running/paused 时调 `abandonRound()`，`finished` 态被跳过，会话卡死在 finished。修复：`teardownRound` 对非 idle 一律 `abandonRound()`，`session.ts` 的 `abandonRound` 接受 finished；`tests/session.test.mjs` 补「结算后弃局回 idle」断言。修复后完整复现路径（打完 → 返回 → 再开；打完 → 再来一局）实测通过。
2. **5 行点阵配文与点阵重叠**（见⑩）。
3. 首次浏览器冒烟还发现 `fitBoard` 引用不存在的 `#board-wrap` id 导致画布未自适应（横向溢出 724px）——补 id 后修复，属实现期缺陷未进入验收记录主路径。

## 未验证项与限制

- **iOS Safari 与 Android Chrome 真实设备未测**：全部证据来自桌面 HeadlessChrome 155.0.0.0 的移动视口模拟（触摸为 `pointerType: 'touch'` 的页面内 PointerEvent 派发 + 真实 DOM 点击）；真实设备验收按 VERIFICATION.md 属 M7 汇总，明确保留。
- **音效可听性未验证**：无头浏览器无音频输出，无法确认实际听感与音量；已验证的是开关状态机、合成调用不抛错、关闭音效后视觉反馈完整。WebAudio 振荡器参数（频率/时长/包络）未经真人试听评审。
- **横屏 568×320 与 320×568 窄屏下游戏屏需纵向滚动**（实测 `scrollHeight − clientHeight`：320×568 为 232px、375×667 为 73px、横屏 568×320 为 420px；首版记录的「约 90–190px」为估算值，与实测不符，2026-10-25 复核轮已更正）：画布有 `touch-action: none`，从画布起的拖动不会滚动页面，滚动需从画布外区域（页眉/操作区）发起；这是「下限 0.7 缩放保证可读」与「整屏容纳」之间的取舍，412×915 整屏容纳（桌面 1280×800 余 18px）。
- **暂停覆盖层下的棋盘点选**由覆盖层 DOM 拦截与会话守卫双层保证；真实多指手势、系统级返回手势与真实移动浏览器的滚动惯性未测。
- **教学有效性观察不在本轮**：乘法点阵是否让学生经「几个几」分组而非逐点清数得出总数，需要真实学生/教师实机观察，本里程碑仅完成可读性验收（PLAN.md M4 已知限制延续）。该缺口自 M2 划入至今无完成证据，需在 M7 汇总时继续追踪。
- 自动对局脚本一次因读取竞争（读到 clearRect 与 fillText 之间的空帧）抛出 `answer null`，加固为多帧稳定读取后复测一致；属测试脚本观测误差，与游戏逻辑无关（与 PLAN.md M3 已知限制同类）。
- 本目录截图为验证当时实拍；`16-game-375.png` 摄于 375×667（含底部控件半露，对应滚动限制）。

## 冻结/不重复计分的量化证据（页面读帧）

- 消除窗口暂停（局 B）：答对第 2 题后立即暂停，静置 2.2s（窗口仅 600ms）后读帧——题号仍「第 2 / 6 题」、得分 15、棋盘 12 块与「答对了 +10」反馈全部未变；点「继续」后正常切至第 3 题。
- 答错反馈窗口暂停（局 B）：点错后立即暂停，静置 1.2s（窗口仅 300ms）后「再想一想」与棋盘未变；恢复后窗口走完，可正常作答（+5 计分成功，证明已回 asking）。
- 暂停中输入封锁（局 B）：asking 暂停后向 idx0 与 idx11 派发 2 次 pointerdown，得分 20、无反馈、题号不变。
- 消除窗口连点（局 A）：答对后同块追加 2 次 pointerdown，得分恰 +5（重试价），无重复计分。
- 反馈窗口连点（局 A）：答错后反馈窗口内再点 1 次，结算「答错 1 次」未变多。

## 未验证项与限制

- **iOS Safari 与 Android Chrome 真实设备未测**：无真机。全部证据来自桌面 HeadlessChrome 155.0.0.0 的移动视口模拟；棋盘点选为页面内合成 `PointerEvent`（pointerType 'touch'），DOM 控件为真实点击。真实设备验收按 VERIFICATION.md 属 M7 汇总，缺口保留。
- **音效可听性未验证**：无头浏览器无音频输出。本轮仅验证「音效 开→关」切换（按钮文案与 `aria-pressed` 同步 false）、关音效下完整对局与视觉反馈完整；音色/音量未经试听。
- **本轮未覆盖横屏（如 568×320）**：实现者记录已含横屏档，本轮按任务要求验证窄屏/常见手机/平板/桌面四类，横屏未重跑。
- 验证脚本（非游戏）两次工具性偏差，均不影响结论：①首次答错反馈截图因 toDataURL 先于下一帧绘制而未含反馈行，改为点击后延迟 100ms 抓帧重拍（`v1-05`）；②`find text "暂停"` 曾命中隐藏覆盖层文案导致一次点击失败，改用 `#btn-pause` 选择器后正常。
- 乘法点阵教学有效性（是否经「几个几」分组计数）仍需真实学生/教师实机观察，本轮仅完成可读性目视核对（延续 PLAN.md M4 已知限制）。
