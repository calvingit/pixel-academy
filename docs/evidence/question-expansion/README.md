## 环境与入口

- 桌面 Chrome 156.0.0.0（Macintosh），由 ego-browser 驱动，TaskSpace 8；完整 UA 见 final-round-results.json，不是 iOS 或 Android 真机。
- `npm run serve -- 4183`：p1，真实选择年级、课程、错题、挑战、钱包和道具路径，未注入金币。
- `node scripts/serve.mjs 4185`：p2，独立源站，仅用于注入正式筛选后的题目做渲染／交互回归及更新延后验证，不将这些夹具用于证明正常入口或奖励。
- 最终版本为 `generated-v4:challenge-v2`、`choices-v3`；主要流程在 `generated-v3` 阶段验证，减法补充后另做数学回归、实际题面和最终完整局复验。更新延后验证的目标缓存为 `assets-v1-c3f7f6144e39`，最终完整局实际缓存为 `assets-v1-9b6c75e3fece`；以后修改资源后哈希会变化。
- 脚本是已执行的分轮会话证据，依赖前序 UI、档案和 Page 状态；不能从中间轮直接重放。单独复验应新建受控测试源站与任务空间，不清空日常用户档案、不把示例夹具写入生产来源。

## 失败、修复和验证边界

- 一次回归暴露错题年级更新覆盖原题的问题。已修正为保留首次原题与领奖身份，只更新可见年级并保存实际答案；原存储回归和新增跨年级去重检查通过。
- browser-03 使用了不支持的中间 `:has-text` 定位；browser-09 在 CDP 改变后用了失效 ref。已根据快照改用实际控件定位。
- browser-13 等待了不适用于整数棋盘的 DOM 状态，且未校准浏览器焦点，驱动失败；browser-16 采用真实档案阶段和焦点模拟后完成恢复与整局。
- browser-18 的驱动求解器只认识首批题型，新算式比较未得到选项 ID；browser-19 补齐驱动后在截图和尺寸检查期间正常超时。保留这次超时并在 browser-22 通过真实复活完成，没有改倒计时或重写成绩。
- browser-27 在等待购买确认时错误等待忙碌状态结束。browser-28 确认实际弹窗后，browser-29 从该确认继续完成道具验收；不是重新购买或注入道具。
- 最初 multiple-390.png 其实是跨轮 CDP 设置已恢复后的桌面截图；有效手机证据为同轮设置尺寸后的 multiple-selected-390.png。未把该旧图当作手机覆盖证据。
- 输入包括原生按钮、键盘，以及部分程序派发点击／PointerEvent；不等于真机触摸。页面隐藏时实际暂停，运行计时用浏览器焦点模拟校准，不修改业务时钟。
- 未执行 iOS Safari／Android Chrome 真机、真实部署、教师评审、学生可读性与难度观察或教学效果验证；10 秒是否适合所有多选题仍需真实试玩，不据脚本作答速度判断。
