## 发现的问题与修正

- 首轮自动检查的预缓存闭包断言仍要求旧会话模块。计时已通过新版 RoundSession 接入，并增加 profile、learning 模块覆盖；最终构建通过。
- 提醒后的继续浮层遮挡底排数字：将继续按钮移到棋盘外；同时收紧局内页眉，保留低高度纵向滚动。
- 第二轮视口断言在 resize／Canvas 缩放完成前读取旧宽度而失败。第三轮等待两帧稳定后五档复验通过，原失败截图保留，不把失败当作通过。
- 退出确认期间可能消耗答题时间：确认前冻结，取消后恢复；第五轮验证。
- 档案写入失败可能反复触发过期计时保存：用明确的 PersistenceError 停用持久交易并冻结当前局；真实中止事务已验证。
