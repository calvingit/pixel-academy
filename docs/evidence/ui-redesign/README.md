## 执行与结果

- 首次 `npm run check` 为 74 通过、1 失败：旧场景测试要求绘制矩形超过 100 个，与精简后的装饰不符。改为保留坐标边界／状态栈检查，并检查三款皮肤底色不同；最终 75 项全过。

- `browser-round1.mjs`：首页五档截图；最初断言 scrollWidth 必须等于 innerWidth，在桌面滚动条占 15px 时误报（1265 ≤ 1280，无溢出）。后续改为检查不超出视口。
- `browser-round2.mjs`：验证无内容年级和准备页；原生自动化点击前工具临时改变页面可见性，触发后台自动暂停，随后暂停按钮点击实际执行继续，等待暂停状态超时。诊断追踪确认调用顺序为 visibilitychange → pause → 按钮 togglePause → resume，没有改动业务规则绕过这一现象。
- `browser-round3.mjs`、`result.json`：使用浏览器焦点模拟和 DOM click 避免工具焦点干扰；棋盘按实际画布坐标派发 pointerdown。覆盖空选择禁用、仅三年级不可开始、一二年级混选、暂停、刷新恢复剩余时间、在线与网络层断网重开各一整局。两局均 100 分、首次答对 10/10、各 +30 金币，未注入成绩或修改题目。正常页面错误记录为空。
- 五档首页和局内布局：320×568、390×844、412×915、568×320、1280×900，均无横向溢出；局内画布宽度至少 252px（数字块最小约 76×62px）。低高度允许纵向滚动。数据见 result.json。
- 同轮检查课程列表、错题列表、商店、雪地皮肤预览、收藏资料、折叠记录；截图分别为 courses-390、review-390、shop-390、skin-preview-390、profile-390、records-390。

- 代理实际查看了首页桌面／320px／390px、局内 390px、暂停、皮肤预览及最终窄屏截图，检查文字、数字、间距与遮挡；不是仅以尺寸断言代替视觉判断。

## 后续反馈：手机单屏与信息收敛

用户要求操作按钮无需整页滚动，并减少常驻信息。此节为最终单屏版本，覆盖前文“低高度允许纵向滚动”的旧行为。

- 首页移除品牌长介绍；课程、商店、收藏、错题和成绩收入“更多”原生 dialog。低高度去掉装饰，年级、开始与恢复按钮保持在可见区域。
- 局内隐藏钱包、复活统计与长说明；讲解按需打开弹窗。竖屏三列四行，横屏题卡在左、数字块四列三行；ResizeObserver 测量可用容器，绘制、点击与方向键共用布局。没有将整张画布压扁，也不再以固定最小高度迫使页面滚动。
- 商店和课程只在列表区滚动，返回固定可见；结果页的操作保持可见。弹窗和长列表本身可以浏览滚动，不承诺全部商品与历史记录同时显示。
- `npm run check`：76 项通过、0 失败；新增 board-layout 测试检查紧凑竖屏／横屏的十二块布局、44px 触摸尺寸、题卡不重叠与坐标映射。
- 浏览器使用同一会话 TaskSpace 7，独立 4194 源站；脚本和 JSON 位于 single-screen/。七档尺寸为 320×568、375×667、390×844、412×915、568×320、844×390、1280×800。21 组检查覆盖首页、局内、准备、续局、结算、课程、练习、商店和离线首页：页面无横纵溢出、操作按钮在视口内，数字块至少 44×44px；关键首页／局内及讲解／商店／结算截图已由代理查看。
- 真实规则完整局交替竖横屏坐标点击，100 分、完成 10/10；暂停刷新后恢复、更多入口、课程阅读→练习→讲解弹窗、退出确认和列表返回均已操作。未重跑本阶段的完整断网局，仅重开离线首页；前文完整断网局为初版证据。
