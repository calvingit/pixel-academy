# 几何建筑师玩法说明（M11 首版）

状态：**已实施首版**（按 [M11 实施计划](m11-geometry-architect-plan.md) 决策口径推进，验证记录见 [M11 验证记录](evidence/m11/README.md)）。本文按 [Agent 开发交接](m7-m15-agent-handoff.md) §7 的执行切片编写并随实现校准。

## 定位与首版边界

- 玩法：积木工坊。玩家完成立体图形的**辨认**（看渲染图选名称）、**分类**（把积木放入按形状标注的分区，整组提交）与**搭建**（按题面把积木放到槽位，逐槽即时判定）三类任务；判题基于形状身份与槽位/分区 accept 语义，与渲染位置、放置顺序、操作路径（点选或拖拽）无关。
- 内容：首批 4 种立体图形（长方体、正方体、圆柱、球）18 道任务（辨认 6 + 分类 6 + 搭建 6），全部为通用原创任务，映射 MAP-030（`math.geometry.solids` → MA-01A-U05「有趣的立体图形」候选映射，各项核验 pending）；审核记录见 [几何建筑师内容审核](content-review-geometry-builder.md)。仅一年级开放，其他年级显示未开放，不用其他年级内容补齐。
- 配图：6 张原创等轴测 SVG（4 种基础图形 + 圆柱横放/长方体竖放姿态变体），随构建交付并登记 SW 预缓存；训练对象为立体图形，不引入平面图形名称作干扰或候选。
- 判题：走 Learning Core（`evaluateAnswer` / `shapePlaceResult`），按形状身份与可接受集合判题；`shapePlaceResult` 是 `evaluateAnswer` 的粒度分解（错块定位/逐槽状态），不是第二判定入口。
- 不做：平面图形辨认（候选目录无依据单元）、旋转操作与图形运动（交接 §7.1「仅在内容审核明确后扩展」）、自由画布搭建、物理引擎、三维建模、沙盒编辑器（PLAN M11 验收明确排除）。金币零收支、无道具（操作型任务答错可自行纠正）。
- 与数字消除/算术地下城的关系：独立 gameId（`geometry-builder`）、独立存储命名空间与成绩归属；已交付五款游戏的生成器、组卷、存储与成绩完全不动。

## 场景与任务规则

- 单一固定工地场景：上部题面与目标区（分类分区或搭建槽位），下部积木栏；无场景滚动、无地图。
- **辨认（choose）**：呈现立体图形渲染图，从 4 个中文名称候选中单选；候选固定为四种图形名称全集（干扰=其余图形名称），渲染排列组卷洗牌，正确答案不恒在首位。
- **分类（classify）**：4–6 块积木、2–4 个分类区（每区标注目标形状，accept 恰一个形状且各区互异）；点选积木→点选分区放置（或拖拽），全部放好后**整组提交**统一判定；提交后反馈错块（「第 N 块放错了格子」），可撤回重排再提交，无死局。
- **搭建（build）**：题面给出目标结构与 N 个槽位（槽位标注可接受形状集合，等价解可见，如「正方体 或 长方体」）；放置即时判定——放对的槽固定（可点缩略图撤回换块），放错给出可解释反馈并可撤回；全部槽正确即完成。不满足任何槽的干扰块被拒（反馈「这块放不进这里」），不丢块。
- **多解口径**：build 槽位 accept 为形状集合（两种积木均可）；classify 同形状多块的任意分配顺序等价；判题按集合逐成员比较，多个等价正确解都可通过。
- 点选放置为主路径（classify 先选中积木再点分区；build 点槽位时系统自动配一块「有剩余且满足该槽」的积木，玩家也可先选中指定块）；拖拽为辅路径（pointer 拖动，位移超阈值启动，松手命中分区/槽位放置，区外松手=取消归位，触摸中断不丢块）。

## 计分与记录

- **每局 5 个任务**：组卷按题型配额轮转（辨认→分类→搭建逐轮取题，三模式齐备），从正式池 `selectExercises` 洗牌抽取，局内唯一，避开上一局任务 ID（「最近开局 ID」机制）；池不足 5 道阻止开局。
- **不限时**：操作型任务倒计时与操作学习冲突，不继承数字消除的 10 秒计时。
- **计分：首答 10 分 / 重试 5 分**。首答口径：辨认=第一次选择；分类=第一次整组提交；搭建=第一次放置判定（中间槽的正确放置只累计判定次数，不错判、不进重试档；放错块才计错判）。答错不扣分，可撤回纠正、无限重试，无死局；任务完成后 resolving 锁定，连点不重复判定。
- **记录分两列**：**图形作答**（每任务辨认/分类/搭建模式、判定与错判次数、首答）与**放置操作**（点选次数、拖拽次数、撤回次数）分开统计，不以操作结果推断图形理解。成绩按独立 gameId 记入练习记录（与其他游戏记录并列，显式携带 gameId、内容版本指纹，按局次 ID 幂等去重，上限 20 条）。

## 存储与恢复

- 独立存储键命名空间（`pixel-academy:geometry-builder:v1:*`），结构校验与损坏处理沿用现有存储层模式（注入式 KV 门面，单条损坏只丢该条，写入失败保持可游玩）。
- 中断快照保存：完整任务序列（含积木排列、分区顺序、辨认选项排列的洗牌结果）、当前任务、每块归属/每槽已放状态、选中积木、逐任务判定与操作计数、局次 ID、RNG 内部状态。刷新/关闭后提供「继续搭建」，恢复后布局（含已放置积木与选中态）与连续游玩完全一致；快照校验含任务结构再校验与排列一致性（分区按 id 核对语义），损坏按首次使用处理。
- 内容版本不兼容时安全放弃中断局并说明原因，不影响其他游戏数据。

## 一局完整示例（一年级）

1. 首页（数字消除）菜单选择「几何建筑师」进入选择屏：勾选一年级 → 显示「一年级 18 个任务，共 18 个」→ 开始搭建。
2. 任务 1（辨认）：呈现圆柱渲染图 → 候选「正方体 / 长方体 / 圆柱 / 球」（组卷洗牌）→ 点「圆柱」→ ✓ +10（首答）。
3. 任务 2（分类）：积木 [球, 正方体, 球, 圆柱]，分区「球区 / 正方体区 / 圆柱区」→ 逐块点选放入 → 提交 → ✗「第 2 块放错了格子」→ 撤回改放 → 再提交 ✓ +5（重试档）。
4. 任务 3（搭建）：「搭一座小塔：底座用圆柱，塔顶用正方体或长方体」→ 点底座槽（自动配圆柱，✓ 固定）→ 点塔顶槽（配正方体，✓；配长方体同样通过——等价多解）→ 完成 +10。
5. 任务 4（搭建）：把球拖到只收正方体/长方体的槽位 → ✗「这块放不进这里」→ 撤回换长方体 → 完成 +5。任务 5（辨认）：首答正确 +10。
6. 结算：「总分 45 · 首次一次完成 4 · 错判 1 次 · 辨认 2/2 首答 · 分类 0/1 首答 · 搭建 2/2 首答 · 点选 N 拖拽 M 撤回 K」。成绩入记录（gameId `geometry-builder`），金币不变；「再来一局」抽新 5 题。

## 验收条件对照（PLAN.md M11）

| 验收条件 | 落实 |
| --- | --- |
| 平面投影或示意图不混淆二维与立体对象 | 等轴测 SVG 呈现立体特征（球带高光投影、正方体/长方体三面、圆柱顶面椭圆）；渲染截图核对入审核与验证记录 |
| 多个等价正确解可通过 | build 槽位 accept 集合多解 + classify 同形多块任意顺序；判题按集合逐成员测试 |
| 不同屏幕尺寸下拖拽判定稳定，提供点选后放置 | 槽位制 DOM 命中免除像素容差；点选主路径 + 拖拽辅路径（阈值启动、区外取消）；五档视口与模拟器真实触摸验证 |
| 首版不需要物理引擎、三维建模或自由沙盒编辑器 | 范围排除；实现为 DOM 槽位制，无物理/三维代码 |
