# 内容基准与审核边界

本次实现范围来自 2026-10-25 用户提供的 Pixel Academy 研究交接。目标是优先实现已有材料，不继续大规模搜寻教材。

## 数据身份

36 个教材编号是项目逻辑槽位，不是已核验出版物。CH 为语文、MA 为数学、EN 为英语，01–06 为年级，A/B 为上下册。英语低年级正式书名与高年级系列可能不同，未以统一正式书名覆盖它们。

四册录入候选目录，其余 32 册标记 deferred。插入的入学准备、综合实践、数学好玩和复习板块分别使用 PRE、P、A、R 编号；主单元始终使用 U 编号。`order` 表示目录显示顺序。

CH-01A 的八个主单元保存交接中的课次候选，但未包含全部语文园地等子栏目，不宣称是正式完整目录。为区分同类单元，识字、阅读与拼音标题中的（一）（二）（三）是项目展示标签，未宣称教材逐字使用该标题。

MA-01A、MA-02A 的 lessons 仅保存交接中的代表课次（examples），不能视为全部课次。EN-01A 采用六单元候选目录，不录入旧版十二单元目录，且尚未提取课次。教学目标不可仅由目录标题确认。

## 来源边界

`handoff-2026-10-25` 是唯一实际录入的证据记录，类型为 conversation-handoff。locator 指向本文，便于追踪录入上下文；它不是教材原件证据。本轮没有重新验证前序官方网页、第三方教学资源或 PDF，旧会话 citation ID 不可解析，因此没有把它们伪装成有效来源链接。

前序研究提及 MA-02A、MA-03A 的 ISBN 候选，但尚未复核原件，也未确认深圳实际使用版本，因此未填写 ISBN。

后续补证时添加可访问的 URL、文件标识与具体页码，并扩展 Evidence 类型；当前不预建抓取系统。不得仅因内容出现在交接中，就把来源状态改为 verified。

## 状态分离

| 字段 | 对象 | 含义 |
| --- | --- | --- |
| sourceVerification | 教材、目录、映射 | 是否完成原始来源核对 |
| localAdoptionVerification | 教材 | 是否确认深圳目标学年实际选用 |
| curriculumVerification | 知识点映射 | 是否按正文及教学要求核对关联 |
| review.status | 练习 | 是否完成练习内容审核 |

正式取题只接受 approved 练习。审核记录必须包含 reviewer 与 ISO 时间。该字段由受信任的静态内容维护者管理，不是权限或审批系统。教材来源待核验不自动禁止独立编写、已审核的通用练习运行，也不能因此宣称这些练习已与特定教材版次精确对齐。

首批 18 道静态练习已按 [首批审核记录](content-review-first-batch.md) 晋级 approved，乘法采用点阵呈现。数字消除正式模式现使用本地生成的候选题库，生成范围、代理审核与限制见 [生成规则审核](content-review-generation.md)；生成结果经结构校验后仍由 selectExercises 正式筛选。静态样例用于旧局次恢复、回归及显式候选预览；默认 Learning Core 导出的静态 catalog 不变。知识点与单元关联仍为候选，不表示完整覆盖或精确匹配教材。

## 数据层使用约定

数组带 readonly 类型约束，但对象没有深度冻结保证；调用方不得通过类型断言或 JavaScript 修改已创建 Core 的底层数据。新增或修改内容后重新调用 createLearningCore。validateCatalog 校验静态 TypeScript 数据的引用完整性、重复 ID、跨学科关联、审核元数据及数学任务；不是用于不可信 JSON 的运行时 schema 校验器。

题目采用结构化任务，不存可执行表达式或冗余答案。`number` 表示识别给定数字的原型任务；`binary` 表示两个整数运算；`chain` 从 start 开始依次执行 steps。新增 `choice` 保存结构化问题与固定候选，候选内容可为数字、比较符号、布尔判断或结构化算式；单选提交选项 ID，多选提交无重复 ID 的集合。正确答案由题意和候选推导，不把布尔判断编码为整数。题目文字、图示和控件留给游戏实现。整数任务判题接受安全整数或十进制整数字符串，拒绝空串、布尔值、浮点字符串、表达式及非有限值。扩展规则、年级边界与代理审核见 [题型扩展审核](content-review-question-expansion.md)。
