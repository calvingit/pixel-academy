# 游戏风格实验室

九款游戏的独立 HTML / Canvas 视觉原型，对照 `docs/game-concepts/minigames/` 的概念图制作。明亮像素场景、木牌标题、清晰题目卡和彩色按钮共用一套掌机外框。

## 预览

在仓库根目录执行 `npm run serve`，打开：

[http://127.0.0.1:4173/game-style/index.html](http://127.0.0.1:4173/game-style/index.html)

若本地服务已经运行，直接访问即可。该目录也可以由任意静态 HTTP 服务单独托管，无需编译或安装依赖。

- 左侧导航（手机为横向列表）切换九款场景。
- 点击选项显示选中效果；暂停 / 继续、Esc 继续、重置、上一个 / 下一个均可操作。
- 动画仅用于角色轻微浮动与星光，尊重系统减少动态效果设置；页面不可见时停止绘制。
- 拼音的声音按钮只有视觉反馈，没有语音。

## 边界

全部文件位于本目录，不引用 `src/`、Learning Core、正式题库、现有游戏规则或存档，也不注册 Service Worker，不修改正式入口。不判题、不计分、不保存记录；题目与短文均为界面展示文案，未作为教学内容审核。九款画面不代表 M7–M15 验收完成。

`index.html` / `style.css` 负责导航、掌机外框、题目和原生按钮；`scenes.js` 存放展示文案；`render.js` 绘制像素场景；`app.js` 接线预览交互。Canvas 使用 180 × 250 逻辑像素绘制到 360 × 500 画布，再随容器等比例显示。中文、拼音与英文使用 HTML 文字。
